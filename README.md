# Görev Panosu

Bootstrap 5 ve vanilla JavaScript ile yapılmış; görevleri tarayıcı LocalStorage alanında saklayan CRUD uygulaması.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın.

## Özellikler
- Ekleme, listeleme, düzenleme ve silme
- Tamamlandı durumu ve filtreler
- Son tarih ve LocalStorage kalıcılığı

Netlify üzerinde statik site olarak yayınlanabilir.
